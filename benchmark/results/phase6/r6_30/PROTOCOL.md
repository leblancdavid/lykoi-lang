once before any model performance. These are small arithmetic/Boolean software
endpoints, not a representative sample of software engineering. No model receives
another track's source. Functional requirement text and shared host contract are
identical, with track-specific construction docs. Hidden context exclusion and
effective reasoning are unattested; classify comparative observations exploratory.

lean ordered-expression intent deterministically generated into Python. Existing

R6.25-qualified four-tool construction route, R6.23/R6.18/R6.10 semantics. C is
experimental Lykoi, not production execution. No opaque Python central behavior.

`openai/gpt-6.1-sol`, requested high reasoning, max4096 output tokens/response,

wall. C Session's unchanged internal24-call bound also applies per attempt.

be run with run_case; acceptance cases are withheld. Syntax/semantic failures
and all candidate attempts are retained. Freeze all contracts/oracles before
authoring. Qualification compares every expected observation with separately
scripted native semantics before freeze, with no candidate implementation involved.

process terminates. Explicit prompt delivery is audited, but hidden-context

byte-for-byte. They test additive extension, not in-place migration/refactoring;
original acceptance must still run on the deployed original endpoint.

code/stage and conceptual failure step. Native C error node is mapped to its
ordered typed step; alias spelling is irrelevant. First submitted candidate and
last selected candidate are evaluated after processes terminate. No outcome-driven
repairs, task substitutions or expectation changes. Report runtime exceptions
separately from specified rejections. Finite acceptance is not universal correctness.

calls, session wall, assistant-message elapsed (not pure inference), development

values remain null. Report separately preparation, orchestration and author effort;
coordinator model telemetry is unavailable and total cost cannot be attested.
