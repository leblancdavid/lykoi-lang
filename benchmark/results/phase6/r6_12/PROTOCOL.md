# R6.12 bounded three-track development comparison — protocol 1

Owner authorization: the R6.12 request in the initiating conversation. No language
changes, P6-A04 acceptance execution or P6-A05 access are authorized.

## Prospective freeze and budgets

Baseline is recorded and production/VM checks complete before task selection.
Five new tasks will be prepared by a separate fresh task session instructed not
to inspect language capabilities or previous benchmark tasks. This is operational
prompt separation, not independently attested cognition or filesystem containment.
The preparer writes shared contracts and explicit acceptance observations before
authoring. Three separately stored modifications are frozen at the same time.
No R6.11 task or CFG66/DSV66/BXC66 is scored. Provenance must disclose synthetic
authorship and any exposure. No oracle edits after freeze.

Tracks: A standard-library Python; B frozen production compiler/runtime only;
C frozen R6.10 semantic-plan-1 only. Transport may serialize inputs/outputs and
invoke ordinary APIs, but must not implement central task behavior for B/C.
Capability gaps are legitimate terminal results; static assessments are distinct
from executed compiler/interpreter failures. Unsupported tasks remain in coverage
and overall success denominators, but never in successful-development averages.

Each task/track/stage: 900 seconds wall budget, at most three candidate attempts
(initial plus two repairs), subprocess timeout 10 seconds per case. Entire track
session cap 4500 seconds base, 2700 seconds modifications. Stop immediately at
success or an evidenced capability gap. No measurable token ceiling is asserted.
One trial per task/track/stage; repetitions are verification, not new development
trials. Setup and testing seconds are separately recorded where obtainable.

## Assignment and disclosure

All tracks use fresh task-agent sessions with the inherited available model,
nominally OpenAI openai/gpt-6.1-sol; exact subagent reasoning/provider routing is
unattested unless tool metadata reports it. No configuration change or credential
inspection. Assign complete common requirements and own workspace only. Prohibit
other-track reads. Base authors must not read modification files. Freeze hashes
before dispatch. Modification authors get a fresh session, their own preserved
base implementation and only the assigned new contract. Log observed reads and
disclosures; unavailable full access logs mean blindness cannot be certified.
Mark contamination if later requirements were read before stage assignment.
Dispatch order A,B,C; modifications C,B,A to offset order effects weakly. Parallel
sessions introduce resource contention; no causal order-control claim.

## Telemetry and interpretation

Record UTC starts/ends, monotonic test execution seconds, attempts, repairs,
commands, artifacts, input/expected/actual observations and return codes. Actual
input/output/reasoning/cached tokens, model calls and USD cost are null unless
returned by the harness/provider. Task dispatch counts are not model-call counts.
Source length is never a token proxy. Subagent elapsed time includes documentation,
tools and testing; subtracting test time is a qualified residual, not pure AI time.
Fresh sessions do not establish OS or hidden-provider isolation. No new isolation
framework. Missing telemetry/attestation caps any finished comparison at
R6_12_EXPLORATORY_COMPARISON_ONLY; incomplete required comparison is PARTIAL.

Acceptance uses type-preserving JSON equality and shared externally observable
results. Original cases run again with each modification; count original failures
as regressions only relative to originally passing observations. Record runtime,
compiler/interpreter, timeout, capability and infrastructure failures separately.
Finite suite success is not universal correctness or long-term maintainability.
Report per-task and aggregate denominators, matched-success effort only, selection
bias, exposure, tooling asymmetries and small-sample uncertainty. No significance
or advantage claim without evidence. Stop after publication and integrity checks.
