# T2 — Ordered run expansion

First byte version1 required (version2 reserved/unscored). Empty TRUNCATED at0;
other nonreserved versions VERSION at0 immediately. Remaining bytes are zero..8
records (count,value). Before reading ninth record OCCURRENCE_LIMIT at17. Read
count, immediately check0..4 else RUN at count's byte, before reading value.
Missing value TRUNCATED at EOF. Zero count still requires value, but emits nothing.
All records structurally validated before publication. Return ordered list of values,
each repeated count times, and identical byte sequence as output. Preserve duplicates
and run order; no sort/merge. Eight count4 runs produce32 values; empty succeeds.
