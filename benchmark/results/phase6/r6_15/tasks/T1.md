# T1 — Saturating calibration

Input exactly three bytes: mode, x, y, all UInt8. Empty input TRUNCATED at0.
Read mode first: only0 (standard) or1 (boost) admitted; other nonreserved modes
reject MODE at0 immediately, before shortage/trailing. Mode2 is reserved, unscored.
Then read x and y; shortage TRUNCATED at EOF. Then require EOF: extra bytes
TRAILING at3. Only after structural reading calculate raw=x+y+(10 if mode1 else0).
Amount=min(raw,200); clipped is the Boolean raw>200 (not raw>=200).
Return value exactly `{amount:integer,clipped:Boolean}` and two output bytes:
amount followed by1 if clipped else0. No wrapping; zero and255 inputs admitted.
