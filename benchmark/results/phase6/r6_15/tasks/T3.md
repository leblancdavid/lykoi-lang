# T3 — Ordered disjoint windows

Input zero..8 records (start,end), two UInt8 each. Before ninth record reject
OCCURRENCE_LIMIT at16. Read start, immediately require<=15 else RANGE at start.
Read end (shortage TRUNCATED at EOF), immediately require<=15 else RANGE at end.
Then require start<=end else ORDER at start. Then require every earlier end<=start
else OVERLAP at start. Perform these checks before reading next record; no sorting.
Zero-width windows and touching endpoints admitted; input ordering mandatory.
Empty valid. Return ordered list `{start:integer,end:integer}` and output count byte
followed by original records. Duplicate zero-width windows valid; duplicate positive
windows overlap. All errors publish no prefix, even after earlier successful records.
