# T4 — Bounded nesting trace

Input zero..8 single-byte symbols '(' (40) and ')' (41). Before reading ninth
symbol OCCURRENCE_LIMIT at8, even if invalid. Unexpected symbol SYNTAX at its byte.
Start depth0, pairs0. '(' increments depth; if new depth>2 reject DEPTH at that
symbol. ')' at depth0 rejects UNDERFLOW at that symbol, otherwise decreases depth
and increments pairs. Process left to right, first failing symbol wins. At EOF,
nonzero depth UNCLOSED at EOF. Empty valid. Return `{pairs:integer}` and one output
byte pairs. This is a bounded structured-delimiter state machine, not a byte-parity
or historical codec task. No whitespace skipping or text preflight.
