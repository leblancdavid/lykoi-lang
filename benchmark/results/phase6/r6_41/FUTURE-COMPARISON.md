# Future compact/expanded comparison qualification

These criteria are a prospective proposal. They neither amend R6.40 scores nor
authorize a benchmark or semantic change.

## Required gates before authoring/exposure

1. **Requirement authority:** human clarification of coordinate systems, derived
   value/region-return rules, observable provenance fields and work/limit equivalence.
   Freeze explicit examples for internal versus post-return checks, constants,
   reversed operands, repeated calls and nested calls. Under-specification blocks
   qualification rather than being resolved from candidate outcomes.
2. **Independent acceptance freeze:** a requirement-authoritative reviewer independent
   of candidate construction approves exact behavior and provenance expectations
   before candidate exposure. Publish pins, reviewer input boundary and limitations.
   Same-coordinator “candidate-independent” is not independent review.
3. **Identical functional contract:** exact result types/values/output/consumed input,
   rejecting inputs, error codes/stages and ordered failure precedence. Include
   malformed input, type/overflow/encode boundaries and declared resource behavior.
   Input provenance is part of this contract whenever explicitly required.
4. **Explicit coordinate correspondence:** identify input-byte, runtime-node,
   symbolic definition/local/occurrence and optional expression coordinates. Publish
   a deterministic total relation for compared sites with unmapped/ambiguous-site
   rejection. Node correspondence cannot overwrite numeric input offsets.
5. **Faithful expanded control:** for a representation-only compactness comparison,
   supply the exact normative expansion including all seq boundaries, expression
   substitution, checks, encode and work/depth effects. Require full envelope identity
   modulo only predeclared ID correspondence. A flat-template condition is a different
   control; separately qualify it and disclose any span/work differences.
6. **Immutable rules:** no post-result expectation changes, correspondence tuning,
   silent node normalization, discarded failures or runtime repairs. Any prospective
   amended contract starts a separately labeled round and preserves first outcomes.

## Scoring and accounting

Report separate counters for functional failures, provenance failures, static/
identity failures and protocol/resource stops. A provenance-only failure remains
full-contract failure when provenance is required. Publish actual work and its
differences even when exact work is not scored. Freeze whether lowered work must
match, whether independently authored forms may have different work, and which
limit-cutoff observations are required. Do not conflate logical work with wall time.

Check node existence plus the correct mapped operation/site, not just membership
in any map. If both origins are metadata, validate exact pins, call occurrence,
sidecar completeness and raw-error preservation separately. Additional metadata
generation/retrieval/validation/storage costs must be measured in future efficiency
claims. No weakened byte-origin rule merely to equalize compact and flat scores.

Maintain identical foundation/model limits/access when model authoring is later
authorized. Obtain a real human control or explicitly frame an AI-selection
comparison, match aggregate capacity and supplied documentation, and meter full
discovery/setup costs. These R6.40 limitations do not disappear after provenance
clarification. No new AI task is needed for the smallest qualification below.

## Smallest next experiment

After clarification and separate authorization, freeze a **model-free, unscored
bounded micro-qualification**:

- One small compact package over existing byte/Int64 operations, a boundary-preserving
  exact expanded twin, and one separately authored flat counterpart.
- An internal check on a supplied byte; a caller check after a composition returns
  arithmetic; two sibling instances sharing one definition; one nested call. These
  can be variants of one small fixture, rather than a new discovery corpus.
- Inputs producing success, each first error, conflicting checks, and every work
  cutoff0..completion+1 for those short paths. Include a constant/site and reversed
  add operand control to distinguish region spans from left-operand provenance.
- Independently frozen exact values/codes/order, raw spans/offsets, mapped primitive
  sites, definition-local identities, ordered caller chains and logical work. Publish
  the chosen flat-form correspondence before observing execution.

Success criterion: compact and exact expansion match the full specified envelope;
flat form satisfies the same functional contract and every declared provenance/
work rule or is explicitly disqualified. Evidence must retain both intentional
representation differences and unexpected failures. Do not reuse R6.40's expected
offsets as unexplained authority or rescore its artifacts. This qualification is
smaller than a fresh adaptive-discovery pilot and introduces no new operation.

If clarification requires a currently unavailable input-lineage meaning, first
publish a separate semantics/interface proposal rather than running this comparison
under improvised attribution. R6.41 stops here.
