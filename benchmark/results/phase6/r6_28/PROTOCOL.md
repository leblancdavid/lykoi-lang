# R6.28 — single unscored semantic construction protocol

Owner authorization is the R6.28 request in the coordinating session. One fresh
GPT-6.1 Sol authoring session, maximum 12 semantic tool requests and four correction
turns. A correction turn means a tool request following an error feedback; consecutive
requests after the same error count separately (a conservative enforceable ceiling).
Stop dispatch after successful validation or either ceiling. Maximum 17 completion
steps, 240-second process-tree deadline; no second authoring session or manual repair.

Use R6.27's object-root annotation and verified UTF-8 stdin OpenCode route. Publish
the original four semantic descriptions, dispatch unchanged arguments through R6.25
normalization into the real unchanged R6.24 Session/R6.23 adapter/R6.18 wrapper.
No echo endpoint, new semantic operations, production edits, training, P6-A04
acceptance or P6-A05 access. The production kernel remains 26.

Freeze requirement, acceptance observations, prompt, exposure, implementation and
configuration before participant inference. The coordinator designs a synthetic,
capability-tailored feasibility requirement; no independent sourcing, blinded
selection, competitive scoring or generalization claim. The participant receives
the requirement and interface contract, not an earlier completed solution. Same
model family as coordinator; hidden-context exclusion is unattested.

Functional success requires completed model-authored definition, unchanged typed
validation, expansion and VM execution meeting every frozen observation. Schema
validity is insufficient. Invalid typed argument observations may reject in the
wrapper before the VM; report their actual stage. Native arithmetic/encoding errors
must remain native, without invented guards.

After author process termination, separate offline evaluation and three saved-artifact
replay passes issue zero inference requests. Compare complete serialized VM envelopes
(typed value, provenance, work, output/error), expanded identities and ordered entry
traces. Trace instrumentation delegates unchanged VM behavior and verifies its result
against the public uninstrumented executor. Timing is excluded from deterministic
identities and retained separately. Never reconstruct or repair a candidate for replay.

Capture SDK completion steps, actual tool requests, argument validity, failures,
corrections, token/cache/cost counters, process wall and deterministic phase timings.
Effective reasoning, raw upstream requests, hidden retries, pure inference time and
API billing are unavailable unless independently returned; do not infer them from
requested high variant or SDK zero cost. Preserve raw session export/events/MCP log.

Classify supported only on complete functional and AI-free replay success; otherwise
partial for incomplete construction, model authoring gap for exhausted/model-refused
authoring, tool integration gap for route/backend failure, protocol halt for invalid
freeze/preservation/budget integrity. Publish terminal evidence and stop.
