## What closed and how it was challenged

The new facts explicitly carry scalar types, exact enum domains, raw preservation,
creation input/literal/resource bindings, omitted-input/default boundaries,
validation errors, ordered whole-record listing, guarded transition meanings and
explicit historical field defaults. Native projection does not parse display
prose. Whole-FRC V1 recovery checks exact typed meaning. Deterministic lowering
uses existing v0.3 record/enum/assignment/guard/transition/capability/migration
constructs; no new primitive is hidden in an application adapter.

Coverage rejects missing/extra/stale facets and unsupported additional obligations.
Closed producer output rejects string-nullability, boolean/integer writes,
transformations and unauthorized default scopes. Source evidence loss, reviewer
typed disagreement, context disagreement and missing owner approval still halt.
Existing policy/clarification/controller regressions pass. The unchanged adequacy
engine still rejects omission of default decision authority as underspecification.

Three published primary public cases produce **51 external process invocations**
with successful creation/reload, exact supplied values, declared defaults,
invalid scalar/enum input, source-guarded transitions, repeat/missing-ID rejection,
explicit migration, current-schema idempotence, invalid historical-value refusal,
missing-store preservation and identical controller audit after reopening SQLite.
All three pass normal FRC→structure→BDI→adequacy→V1→author→compile→external stages.

Additional executed tests cover:

- existing-model v2→v3 field introduction, preserving prior migration and lifecycle;
- finite enum expansion in a laboratory model, including CALIBRATION creation;
- a gallery equality query against a prior normal scalar model, distinguishing
  exact spaces and case through the existing CollectionQuery comparison path;

These are bounded compositions. They do not establish arbitrary profile
composition, complete decision discovery, all string encodings, numeric operations,
relationships or general state-machine/migration programming.

## Completion answers

1. **Orphans:** generic writable scalar/default/optionality, raw preservation,
   identity/lifecycle/resources and additive migration existed in the compiler but
   lacked normal typed projection/profile/authoring. Query booleans/integers were
   read-only orphans relative to writes; arbitrary existing guard/filter amendments
   remain normal-projection orphans.
2. **Closed seams:** typed producer/schema/guidance→reconciliation→deterministic
   structure/coverage→existing BDI/adequacy→faithful normal V1→restricted author→
   existing compiler/runtime→declared-store external verification, for tested mappings.
3. **Scalar/enum/default/optionality:** yes for bounded string/identifier/finite enum/
   UTC timestamp and existing timestamp nullability, with explicit creation defaults.
   No general boolean/integer writes, arbitrary optional guards or all encodings.
4. **Lifecycle/resources:** yes for single guarded transitions and declared actual
   UUID/UTC creation resources; deterministic creation-provider injection and broader
   guard/clock-relative query integration remain incomplete.
5. **Migration/evolution:** yes for explicit additive literal-default chains and
   finite enum expansion, including evolving an existing normal model. No inferred
   historical policy or general migration program.
6. **Persistence/restart:** correct on tested ASCII/whitespace and declared rejection/
   migration cases, whole unrelated values and stable IDs retained; external processes
   reload and controller audits survive reopen. The Unicode stdout failure remains.
7. **Exposed behavioral successes:** **2/20, B04 and B05**.
8. **Distribution change:** `1/16/1/2 → 2/15/1/2` (success/structure/BDI/clarification).
9. **Progress without new semantics:** **B04**; B05 preserves success.
10. **New downstream missing-family observations:** none newly reached by blocked
    cases; inventory-confirmed demands above remain separate from execution results.
11. **B17/B20 clarification:** yes, both remain blocked; no invented answers.
12. **Proposed R5.103 target:** finish generic existing guard/clock-relative list and
    mixed-profile projection, with complete fresh typed re-formalization of transfer
    cases, before concluding that new families are the next blocker. Typed mutable
    values remain the leading subsequent family candidate across B02/B03/B07/B14.
    This is a proposal, not an authorization or implementation in R5.102.
13. **Benchmark-specific primitive:** none. Benchmark-specific source/oracle captures
    live only in the versioned evaluation script; product code has no benchmark IDs,
    priority constants or source-wording dispatch.
14. **Infrastructure work avoided:** yes. No Python/OpenCode/transport/model
    qualification, firewall or protected-activation work; evidence pins only fix this
    transfer implementation and preserve history, not new research-access gates.
