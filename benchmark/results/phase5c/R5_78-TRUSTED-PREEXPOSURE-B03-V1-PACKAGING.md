## Trusted boundary and error containment

The pure transformation has no I/O, static evaluator, AI/LLM, runner authority,
generation or execution calls. Structural profile validation uses the qualified
V1 validator, not profile support inspection. It does not call the opened-document
adapter or assemble a B03 contract. Its output bytes would remain inside a trusted
controller; only the closed receipt can be published. Failures expose only generic
structural classes, with original exceptions suppressed.

The qualification controller denies protected B02/B03 paths and captured B02
documents. It freezes before tests, captures test diagnostics privately, publishes
counts and generic error codes, and never invokes actual authorization or observe.
No protected source is passed to it. Health workers retain their qualified
protected exclusions. No production protected-I/O/sealing controller is claimed
qualified: the applicable source gate failed before it was needed.

with contained content and safe receipts. Here the stronger boundary holds:
**there was no trusted mechanical B03 access either**. Any future protected
disclosure requires `R5_78_PROTOCOL_HALT` and loss of pristine status; no such
disclosure occurred in this round.
