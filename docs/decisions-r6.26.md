# Decision — preserve exact schemas at the R6.26 compatibility boundary

The authorized comparison requires unchanged semantic tool argument schemas.
The new SDK/MCP bridge therefore copies them exactly and uses existing R6.25
normalization only for nonsemantic call envelopes. Tool discovery fails before a
call envelope exists. No sufficient envelope-only repair was identified.

Record the selected track unavailable through this route and stop before scored
exposure. Do not add root type/flatten oneOf or substitute a different authoring
interface merely to obtain a model score. Preserve the failed neutral attempt and
separate observed discovery failure from unverified causal attribution.

The tradeoff is an inconclusive capability comparison rather than a score with
altered schema visibility. A separately authorized neutral exact-schema exposure
qualification is recommended; any schema representation change needs explicit
scope and accepted-argument preservation evidence before a new freeze.

See [R6.26](../benchmark/results/phase6/R6_26-REPORT.md). No production extension,
semantic change, P6-A04 acceptance, P6-A05 access or automatic continuation.
