# Decision addendum — R6.36

## Observation

One child-only flag removal permits successful access and a complete bounded
AI-authored lifecycle. [Report](../benchmark/results/phase6/R6_36-REPORT.md)
classifies `R6_36_AI_LIFECYCLE_SUPPORTED` after frozen acceptance and AI-free replay.
Safe diagnostics did not attest effective OAuth branch or endpoint.

## Bounded design choice

Preserve R6.33 requirements, scorer and explicit JSON host broker byte-for-byte.
Add four thin MCP transport adapters over unchanged semantic operations for the
requested neutral tool-discovery check. Freeze the callable surface and corrected
configuration before results. Lifecycle prompts retain JSON-only broker mode;
do not claim observed semantic MCP use. Mechanical sealing is identity computation,
not semantic repair. Retain the inherited scorer's raw round label and put the
authoritative R6.36 classification in its own terminal record.

## Consequence and proposal

This demonstrates bounded composition reuse and selective version migration on
one exposed synthetic requirement. It does not establish causal authentication
selection, adaptive generalization or efficiency. Recommend a separately frozen
small unseen task with actual MCP calls and an independent requirement-derived
error-site/order oracle. No full H1/H2 study or automatic continuation authorized.
Production26/history remain unchanged. Stop after publication and await the owner.
