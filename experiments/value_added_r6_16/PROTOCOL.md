## Design and fixed budgets

A authors standalone standard-library Python. B and C independently author the
same closed, declarative intent interface. B uses an experimental deterministic
generator and ordinary structural validation. C translates that interface into
existing production scalar/mutable/predicate IR and invokes existing validation
and Python generation. C must execute production-generated behavior, guards and
invariants; an experimental Python implementation cannot stand in for semantics.
No new Lykoi operations. Unsupported translations are UNAVAILABLE and remain in
the application/phase denominators. Low-level IR access is a research adapter,
not evidence of the owner-approval/normal FRC workflow.

Two newly authored small persistent applications; selection follows capability
inventory, is synthetic, nonrandom and biased toward record-local constraints.
Requirements, explicit acceptance expectations, two cumulative changes/application
and oracle are sealed before any application authorship. Infrastructure is built
from the shared grammar, not author submissions or scored feedback. An infrastructure
defect discovered during scoring terminates affected scores; preserve first output,
and any corrected rerun must be separately labeled, never replace the first result.

One fresh task-level author context per application/track; stages resume its own
context. Same available model openai/gpt-6.1-sol and harness-default reasoning;
configuration/routing independently unattested. Contexts share filesystem and
repository guidance. Comparison EXPLORATORY; stages CONTAMINATED_UNENFORCED even
without observed premature access. Coordinator prepares and knows all changes.
No other-track sources or oracle feedback supplied to authors.

Each application/track/stage: 300-second cooperative wall budget, 12 tools, one
candidate plus at most one self-test repair, at most two development batches <=30s.
No acceptance-feedback repairs. Preserve first submitted artifact and final bytes
before acceptance. No hard model-session termination or token limit is claimed.
All failures and missing candidates count. Prompt/IR/schema/generator/validation
overhead included or reported separately as shared setup, never amortized by fiat.

## Evaluation and attribution

All tracks receive identical formal application requirements and released changes.
Use a common subprocess oracle, <=30s/child, fresh storage per scenario, restart
between operations. Check exact type-sensitive observable results, state/rejection
preservation and persistent reload. Dynamic IDs/time are fixed through explicit
test providers or normalized by the transport only. No task computation in transport.
Original cases retained at both stages unless an explicit requirement supersedes
them; report supersession separately. Frozen submitted artifacts immutable.

For C distinguish compile-time typed/effect defects from runtime guards/invariants;
neither proves correspondence to requirements. Seeded controls run separately from
scored authorship: malformed semantic references, incompatible types, unauthorized
effects, well-typed wrong behavior, and violated persisted invariants. Give B/A the
equivalent control opportunity. Attribute only checks not supplied by common schema
or B ordinary validation. Impact traversal is structural information, not proof.

Measure correctness, old/new pass counts, passing-to-failing regressions, first/final
candidates, repairs, author calls/tokens/cache/reasoning where actually exported,
wall/tool time, API cost (null if billing unavailable), shared setup and representation
bytes. Token bytes are not usage. Failed applications never disappear from totals.
No independently attested author or controlled causal efficiency claim.

Publish all evidence and one authorized final classification. Lykoi value requires
an observed advantage specifically attributable to semantic validation. C absence
does not imply B sufficiency; incomplete comparison does not imply A superiority.
Verify all baseline hashes, submission/requirement seals, scope and git diff --check
including new-file whitespace. Update additive current guidance; stop after publication.
