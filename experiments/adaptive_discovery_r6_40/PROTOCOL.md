# R6.40 — Bounded adaptive discovery pilot

Authorization: owner's R6.40 request and subsequent explicit authorization of an
AI-designed B proxy. B is **not human-designed**; a discovery-specific benefit over
human macros cannot be established. No full R6.31 study is commissioned.

## Prospective sequence

1. Verify R6.39 publication and inherited protected identities; kernel26 inherited
   accounting backed by unchanged files. Freeze development contracts, expectations
   and coordinator-AI-designed proxy pool before selecting evaluation tasks and
   before participant discovery. Pool design has access only to development.py.
2. Freeze six new coordinator-selected synthetic evaluation requirements and
   candidate-independent expectations before participant exposure. Two direct,
   two combination, two negative-transfer contracts; narrow existing byte/arithmetic
   foundation. Coordinator knows both partitions; discovery child has only development
   contracts. Hidden-context exclusion is unattested: exploratory evidence only.
3. Preselect openai/gpt-6.1-sol high through existing R6.36 OpenCode child route.
   Built-in plugins remain eligible; no credentials/configuration stores inspected.
   One neutral call may qualify route, without task content.
4. Three fresh discovery sessions, one per development contract. Permit original
   foundations and earlier admitted candidates. At most nine proposals total, three
   per session, at most three admitted entries, 24 authored body steps/library,
   16KiB library including applicability docs. Typed signatures use frozen relation
   contracts; participants select reusable representations, not execution meanings.
   This bounded relation inventory limits originality and external generalization.
5. Every proposal declares relation, precise semantics, non-applicability, definition.
   Registry machinery performs only identity sealing. Test signature/representation,
   exact pinned closure, deterministic expansion, frozen development observations,
   two reloads. Keep all raw failures; no coordinator semantic repair. Failed behavior
   cannot enter the reusable vocabulary, even if structurally registry-valid.
6. Freeze admitted definitions, descriptions, diagnostics and identities. Preserve
   empty library if necessary. Deterministically choose matching proxy entries by
   same relation/arity/type, body steps within one or10%, nesting equal. Report
   matching failure without editing either library. Docs exposure within10% is
   measured, not assumed. Account full proxy-pool cost as unavailable coordinator
   model tokens and measured pool-admission time.
7. Six tasks x four conditions =24 fresh evaluation sessions. A primitive-only;
   B sealed matched AI-proxy macros; C admitted discovered macros; X expanded
   bodies and equivalent applicability docs, with no library pins. All can author
   task-local definitions but cannot write reusable vocabulary. Root name Entry,
   params[], Int64 result, UInt8 input, end-before-computation, UInt16BE output.
   Rotate A/B/C/X, B/C/X/A, C/X/A/B, X/A/B/C, A/C/B/X, X/B/C/A.
8. Seal first complete submission and final submission; at most three submissions.
   Acceptance is offline after all final artifacts seal; no acceptance feedback or
   cross-condition artifacts. Selftests use author-selected bytes only. Exact
   success value/type/bytes/spans and rejection code/stage/site offset, malformed
   input precedence, pinned dependencies, expansion and work controls are scored.
   Two AI-free replay passes compare entire execution envelopes/expanded plans.

## Fixed limits

Each session:360s process wall,24 completion calls,36 MCP construction calls,
48,000 reported processed-input+output tokens (cached read/write counted), three
proposals/submissions, twelve public execute calls,64 expanded nodes,32 authored
steps/definition,8 definition closure,depth4, original VM work budget100,000.
MCP cumulative CPU/wall120s, call30s. Limits checked at observed boundaries; no
claim of exact hidden-provider budgeting. Tool facade refuses over-budget calls.
Streaming supervisor terminates after visible completion/token cap; retain overshoot.
Inference wall stops whole process tree at deadline. Scorer30s/task, finite cases
only; signature/negative/type/limit checks included. No retries of provider halts.

## Interpretation and accounting

Separate validity, discovery, successful dependency-entered reuse, unseen transfer,
benefit over primitive vocabulary and AI-specific attribution. Negative tasks
challenge applicability; useful library need not be invoked there. Library identity
alone proves no behavior. All tokens/cache, calls, retrieval, repairs, wall, tool,
validation/lowering and execution intervals retained. API billing, effective
reasoning/authentication and coordinator model usage unavailable; never infer zeros.
Discovery is charged to C and X in individual comparisons, not divided between
them. Break-even uses observed saved processed input per successful reuse only;
negative/zero savings or missing fully metered effort cannot establish economy.
No statistical significance or internal language-of-thought claims.
