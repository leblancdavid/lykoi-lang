## Evaluation and replay

Seal submitted artifacts when the run process exits; do not resume participant
sessions. Build B only through unchanged production generator; A syntax check.
Score first and final against frozen modified observations. Retained original
expectations are checked under the modified contract, with five explicit original
supersessions. Original expectations are also run diagnostically on final code;
superseded failures are not regressions. Each invocation is a fresh subprocess.
Observe result, persisted records, rejection/read exact bytes, selected/unselected
state and errors. Repeat final evaluation independently without any AI call;
compare deterministic result/state/stdout/stderr/byte identities excluding timing.
Also execute predecessor then successor against the same store and copied installed
application path; retain storage across installation. No migration or normalization.

Static production impact output is diagnostic only. Its legacy index may omit
typed extension predicates; never use it as the expected-impact oracle.
