# R6.39 prospective three-condition comparison

Three new synthetic byte-domain scenarios, selected by the coordinator within the
unchanged R6.18 operation allowlist. Shared base construction is authored once per
scenario, before disclosure of the modification; exact admitted registry bytes are
cloned into A/B/C. All modification sessions are fresh. A receives complete relevant
exported construction conversation/actions/feedback as an explicit history document;
B receives a deterministic behavioral/interface summary and identity index; C receives
the unchanged R6.38 snapshot format generated from the same registry and frozen facts.
No LLM generates B or C. A is history rehydration, not an accumulating native session.

All receive the same guide, modification text, model, requested high variant, tools,
and bounded retrieval of all three context documents and exact registry details.
No participant has filesystem or cross-condition tools. Hidden provider/harness
context exclusion is unattested: all findings are exploratory. Order is T1 A/B/C,
T2 B/C/A, T3 C/A/B. No repetitions beyond one modification session/condition/scenario;
no statistical significance claim. Shared construction is separately accounted and
one-third allocation may be reported without pretending it was independently repeated.

Freeze requirements, requirement-derived expected values/errors, evaluator and
protocol before construction. Freeze actual context documents and audit before any
modification authoring for that task. Budget per base or modification: 20 observed
completions, 40 MCP calls, 600 seconds total including corrections, at most 2 correction
turns. Wall limit is subprocess-enforced; call limits checked at stage boundaries,
not hard inner-loop gates. Any exceedance invalidates that run. Infrastructure/provider
failure halts the experiment; retain partial evidence without outcome-informed tuning.
Functional failures receive at most 8 frozen failed observations per correction.

Scoring checks old and retained caller observations, successor behavior, exact pins,
selective migration, unchanged caller structure except compose pins, ordered source
labels/error offsets and structural failure precedence. Oracles precede artifacts;
same-coordinator task/oracle design is not independent cognition or external sourcing.
AI-independent replay uses separate Python processes, no provider calls, three passes.

Record SDK input/cache/output/reasoning, completions, tools, retrieval, wall intervals,
context generation/audit and acceptance/lowering/execution times. Preserve exports and
MCP exchanges. Local ceil(characters/4) estimates are not model tokenizer measurements.
Billing, hidden HTTP retries, exact provider serialization, effective reasoning and
coordinator tokens are unavailable unless exposed; missing values stay null. Never
claim fully accounted effort or uniquely symbolic benefit from context volume alone.

Publication is additive, protecting R6.38 manifest and all inherited SHA256 identities.
Production26/VM/wrapper/adapter/contracts/registry/telemetry unchanged. No R6.31 full
study, new execution semantics, training, P6-A04 acceptance or P6-A05 access. Stop after
publication. Classification must distinguish observed correctness/reliability/fully
accounted effort advantage from mere descriptive participant-token differences.
